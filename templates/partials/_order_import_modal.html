📋 CSV File Formatting Guide:
Expected headers: {{ columns }}
  • One row per {{ item_label }}. Rows with the same order number become one order; leave it blank to auto-number. Order details are read from the order's first row. Dates can be YYYY-MM-DD or DD/MM/YYYY.
  • New orders: leave status blank. They are created as Draft, or sent to Pending Approval when approver names a user who can approve. The import never approves them.
  • Past manual records: set status to {% if kind == 'so' %}Delivered{% else %}Completed{% endif %} or Cancelled, with the original order_date{% if kind == 'po' %} and completed_date{% endif %}. {% if kind == 'so' %}quantity_shipped{% else %}quantity_received{% endif %} defaults to the full quantity. Needs approve permission; no stock is moved. Orders still in progress must be entered as new orders.
  • Orders whose number already exists are skipped, and an order with any bad row is not imported.
